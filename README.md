# دوّارة

ألعاب جماعية للشلة: المضيف يفتح غرفة بكود من ٤ حروف، الكل يدخل من جواله من المتصفح، وشاشة العرض على التلفزيون. «ميكو» هو الحكم اللي يمسك الجلسة.

## الألعاب
| اللعبة | اللاعبين | الفكرة |
|---|---|---|
| وش قالوا؟ | 4–14 (فريقين) | استطلاع جمهور، جرس مواجهة، 3 أكسات وسرقة، الجولة الأخيرة ×2 |
| جماد نبات إنسان | 2–14 | حرف عشوائي، خمس خانات، ستوب، ومراجعة ورفض بالتصويت |
| مين كتبها؟ | 3–14 | قصص بدون أسماء وتصويت على الكاتب |
| الدخيل | 4–12 | الكل يعرف الكلمة إلا واحد |
| السؤال الشاذ | 3–12 | واحد وصله سؤال مختلف |
| ارسمها | 4–14 (فريقين) | رسم حي من الجوال يطلع على الشاشة |
| ملف القضية | 4–14 | قاتل وشاهد ومحققين |

- **الأسئلة ما تتكرر:** كل سؤال أو كلمة تطلع للمضيف تنحفظ في قاعدة البيانات وما ترجع له. إذا خلص المخزون الجاهز وعندك مفتاح Claude، يكتب أسئلة جديدة.
- **مطابقة ذكية:** «مويه» = «موية» = «ماء»، والأخطاء الإملائية البسيطة تنمشي، وإذا ما تطابقت محلياً يحكم Claude على المعنى (إذا المفتاح موجود). المضيف يقدر دايماً يكشف أي إجابة بنفسه.

## التشغيل
```powershell
npm install
copy .env.example .env    # وعدّل AUTH_SECRET لنص عشوائي طويل
npx prisma db push
npm run dev
```
افتح http://localhost:3000.

### اللعب مع ربعك في نفس البيت
1. شغّل الموقع على اللابتوب (`npm run dev`).
2. افتح غرفة، واللوبي يعرض لك عنوان جهازك على الشبكة (مثل `192.168.1.20:3000`).
3. ربعك يفتحون هالعنوان من جوالاتهم وهم على نفس الواي فاي، ويكتبون الكود.
4. افتح «شاشة العرض» على التلفزيون أو اللابتوب.

إذا ويندوز سأل عن جدار الحماية أول مرة، اسمح لـ Node.js على الشبكات الخاصة.

### اللعب من بيوت مختلفة
تحتاج ترفع الموقع على استضافة تدعم سيرفر Node يشتغل باستمرار (Railway أو Render أو VPS):
```powershell
npm run build
npm start
```
وغيّر `DATABASE_URL` لقاعدة PostgreSQL و`provider` في `prisma/schema.prisma` إذا الاستضافة ما تحفظ الملفات.

## مفتاح Claude (اختياري)
ضع `ANTHROPIC_API_KEY` في `.env` عشان:
- المطابقة بالمعنى (جوال = تلفون = موبايل، وكلمات لهجات ما في القاموس).
- توليد أسئلة وكلمات جديدة لما يخلص المخزون الجاهز.

بدون المفتاح كل شي يشتغل بالمطابقة المحلية والمخزون الجاهز.

## تجربة بدون ربعك
```powershell
npx tsx scripts/bots.ts KZRT 3     # يدخّل 3 لاعبين وهميين للغرفة KZRT
npx tsx scripts/simulate.ts feud   # يلعب جولة كاملة آلياً ويطبع النتيجة
npx tsx scripts/test-matcher.ts    # يختبر مطابقة الإجابات
```
